# Studyroom — Class XII NEB Dashain Homework (2083)

A modern, responsive academic web application and digital notebook for **Class 12 NEB (National Examination Board) Science** Dashain Vacation Homework 2083.

Built by **[Napra (Arpan Bhattarai)](https://linktr.ee/NapraB)**.

---

## 🌟 Features

- **Complete Subject Coverage (313 Questions Total):**
  - **Physics (18 Qs):** Derivations (Laplace correction, Doppler effect, stationary waves) and step-by-step numericals.
  - **Biology (16 Qs):** Botany (DNA structure, Watson-Crick model, genetic code) & Zoology (Human heart, cardiac cycle, digestive system).
  - **English (6 Qs):** Literature analysis, Dashain letter to friend in Delhi, narrative essay, formal Job Application with complete CV, 5-paragraph AI essay, and Working with Words Units 1–10.
  - **Nepali (14 Qs):** Authentic Devanagari answers for Chapters 1–6 (*Aama ko Sapana*, *Birahini Damayanti*, *Ghanghas*, *Byabasayik Patra*, *Ek Chihan*, *Stephen Hawking*) plus Byakaran Padbarga & Shabdaartha.
  - **Computer Science (25 Qs):** Complete C programs across Functions, Recursion, Structure/Union, Pointers, and File Handling (`fopen`, `fprintf`, `fscanf`, `fread`, `fwrite`, `putw`, `getw`).
  - **Mathematics (31 Qs):** 11 MCQs with justifications + 20 Descriptive problems (Induction, De-Moivre's theorem, Cramer's rule, Gauss Elimination, Gauss-Seidel iterations, Simplex method).
  - **Chemistry (203 Qs):** Haloalkanes, Haloarenes, Transition Metals (Copper, Zinc, Mercury, Iron, Silver), and Ionic Equilibrium.
- **Notebook Copy Format:** Strict NEB notebook format (`Question [number]. [Question]` directly above `Answer: [Answer]`).
- **Instant Search (⌘K / Ctrl+K):** Real-time full-text search across all 313 questions with support for English and Devanagari Nepali.
- **Dark / Light Theme:** Apple-inspired dark academic minimalism with persistent `localStorage` theme state.
- **Quick-Action Tools:** 1-click "Copy Q&A", "Copy Link / Share", and "Copy Code" on all C programs.
- **Print & PDF Mode:** Clean `@media print` stylesheet optimized for A4 paper and PDF export.

## 🚀 Running Locally

No build tools or external dependencies required. Simply open `index.html` or run a local HTTP server:

```bash
# Clone the repository
git clone https://github.com/Arpaann/Dashain-HW.git
cd Dashain-HW

# Start a local HTTP server
python -m http.server 8080
```

Then visit `http://localhost:8080` in your web browser.
